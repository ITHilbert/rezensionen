# Kontext & Zielsetzung: ITHilbert Rezensionen

Verwaltung von Kundenrezensionen und Bewertungen.

## Ziel
Integration von Bewertungsfunktionen in die Webseite.

## Hauptfunktionen
- Erfassen von Bewertungen
- Anzeige von Bewertungen als Slider, mit Pause bei Fokus und Pause-Knopf (WCAG 2.2.2, Details in der README)
